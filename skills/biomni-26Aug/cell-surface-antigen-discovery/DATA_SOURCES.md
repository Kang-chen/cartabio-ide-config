# Data Sources & Licenses

This skill integrates several external, public biomedical data resources. This file
records each source, what it is used for in the pipeline, and its data license, so that
outputs (including commercial use) can be produced with correct attribution and
license compliance.

**Compliance summary (read first):**

- Most sources permit **commercial use with attribution** (CC BY 4.0 / CC0 / MIT).
- Two sources are **share-alike (CC BY-SA)** and require special care:
  - **ChEMBL — CC BY-SA 3.0 Unported.** Commercial use **is permitted**, but requires
    **attribution** (include the ChEMBL URL and release version) **and share-alike**:
    any redistributed *adaptation* of ChEMBL data must be released under the same
    (or a compatible) CC BY-SA license. Reached transitively via the Open Targets
    known-drugs / drug-tractability annotations.
  - **Human Protein Atlas (HPA) — CC BY-SA (downloadable data files).** Commercial use
    **is permitted**, but requires **attribution** (cite an HPA primary publication and
    proteinatlas.org) **and share-alike** for redistributed adaptations. The HPA website
    text now states CC BY 4.0 for copyrightable parts, but the **bulk download files this
    skill uses carry the CC BY-SA terms**, so treat the normal-tissue baseline as CC BY-SA
    (the more restrictive, safer assumption).
- Practical implication: a derived dataset that **incorporates ChEMBL or HPA content**
  (e.g. a redistributed table that embeds HPA nTPM/IHC values or ChEMBL drug records)
  should itself be shared under a compatible **CC BY-SA** license and carry the required
  attributions. A **report that cites** these sources (the normal deliverable here) is
  fine with attribution; share-alike bites only on redistributed adaptations of the data.

Attribution for all sources is emitted in the generated PDF's Methods/References and in
`analysis_manifest.json`. This file is the authoritative license record; the References
list in a report is the user-facing attribution.

## Required attribution strings

Include these (or equivalents) wherever the corresponding data is used or redistributed:

- **CZ CELLxGENE Census** — "Data from CZ CELLxGENE Discover Census (CC BY 4.0),
  Chan Zuckerberg Initiative; cellxgene-census software under the MIT license. Record the
  Census version (e.g. `2025-11-08`)." https://chanzuckerberg.github.io/cellxgene-census/
- **Human Protein Atlas** — "Data from the Human Protein Atlas (proteinatlas.org),
  available under CC BY-SA; cite an HPA primary publication (e.g. Uhlén et al., Science 2015)
  and proteinatlas.org. Downloadable files are share-alike." https://www.proteinatlas.org/about/licence
- **Open Targets Platform** — "Target–disease evidence, tractability, and known-drug
  annotations from the Open Targets Platform (integration layer marked CC0 1.0);
  Ochoa et al., Nucleic Acids Res 2023." https://platform-docs.opentargets.org/licence
- **ChEMBL** — "Drug/mechanism data derived from ChEMBL (CC BY-SA 3.0 Unported),
  EMBL-EBI. Include the ChEMBL URL and release version, e.g. 'ChEMBL data is from
  http://www.ebi.ac.uk/chembl - ChEMBL_<release>'." http://chembl.github.io/chembl-licensing/
- **DepMap** — "Gene essentiality from the Cancer Dependency Map (DepMap), Broad Institute
  (CC BY 4.0); Tsherniak et al., Cell 2017. Used as an annotation, not a selection gate."
  https://depmap.org/portal/
- **SURFY / in-silico surfaceome** — "Surfaceome membership/topology from Bausch-Fluck D,
  et al. (2018) PNAS 115(46):E10988–E10997 (in-silico human surfaceome / SURFY)." Table S3 is
  **downloaded at runtime** by `surfaceome_filter.load_surfy_surfaceome()` (from wollscheidlab.org/SURFY,
  with a byte-identical sha256-verified mirror fallback) and cached under the run's output dir; it is
  **not redistributed** in this skill package. Cite the publication.
- **GTEx** (if used) — "Normal-tissue RNA from the GTEx Project (CC BY 4.0)."

## Notes on license compatibility (share-alike)

- **Report / analysis deliverables** (PDF, figures, ranked CSV that reports *derived scores*
  rather than redistributing the source tables verbatim): attribution satisfies the
  license; provide the strings above.
- **Redistributing a derived dataset that embeds ChEMBL or HPA content** (e.g. a table that
  carries HPA nTPM/IHC values, or ChEMBL drug records): the derived dataset is an
  *adaptation* and must be licensed **CC BY-SA** (share-alike) with the required attributions.
  If you must avoid share-alike, do not redistribute those embedded values — report only
  transformed/aggregated outputs and cite the source.
- The remaining sources (CC BY 4.0 / CC0 / MIT) impose no share-alike obligation.

_Verify licenses at the source URLs before commercial redistribution; license terms and
versions can change between releases._
