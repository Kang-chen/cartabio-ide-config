# Reporting Notes (PDF + infographic)

The final PDF is rendered through the **`pdf-report-generation`** skill's Phylo brand system.
`scripts/build_report.py` is a **layout engine** — it reads `synthesis.json`,
`references.json`, the CSV artifacts, the figures, and the infographic, and lays them out. It
authors no science. Load `pdf-report-generation` for the full brand spec.

## Report section order

1. Title page (no cover) — title, gold subtitle, "Generated by Biomni | <date>".
2. **Infographic** (GenerateImage output), full-width, centered.
3. Executive summary + a bottom-line callout.
4. Introduction (the direction question; why multi-axis concordance).
5. Methods — evidence sources + the **direction-mapping rule table** + the confidence-tier
   definitions + the verification protocol + the real `doi_layer_status`.
6. Results — evidence-matrix table (target × axis, colored votes) + heatmap figure +
   consensus table + per-target findings (one short block each).
7. Discussion — regime-/allele-conditional; honest about genuine disagreements; safety-vs-
   direction distinction.
8. Limitations.
9. Next steps.
10. Relevant Biomni resources (from Step 7) — how to run each follow-up axis.
11. References — verbatim, verified, numbered to match `[n]` markers.

## Table layout gotchas (learned during the original build)

- **Set explicit `colWidths`** on every table; letter with 60pt margins ≈ 492pt usable.
- The consensus table's `Consensus`/`Concordance` headers wrap awkwardly if columns are too
  narrow — use widths like `[46,58,66,112,206]` and header font ≤ 7.6pt, or shorten headers.
- Use `repeatRows=1` so multi-page tables repeat the header.
- Wrap each figure + its caption in `KeepTogether([...])` so captions don't orphan.
- Set `hAlign="CENTER"` on every Image, Table, and Drawing.

## Non-ASCII normalization (avoid ■ black-square glyphs)

ReportLab's Helvetica renders many Unicode punctuation chars as black squares. Normalize
reference/title strings before laying them out (this fixes *rendering*, not facts):

```python
import re
REPL = {"\u2010":"-","\u2011":"-","\u2012":"-","\u2013":"-","\u2014":"-","\u2015":"-",
        "\u2212":"-","\u00ad":"-","\u2043":"-","\u2018":"'","\u2019":"'",
        "\u201c":'"',"\u201d":'"',"\u00a0":" ","\u200b":"",
        "\u00ae":"(R)","\u2122":"(TM)","\u00a9":"(c)","\u2606":"","\u2605":"","\ufe0f":""}
def clean_text(s):
    for k,v in REPL.items(): s = s.replace(k, v)
    s = "".join(ch if ord(ch) < 128 else "" for ch in s)
    return re.sub(r"\s{2,}", " ", s).strip()
```
Note: `×`, `→`, `–`, `—` in **narrative body text** render fine and are intentional; the issue
is specifically stray Unicode inside reference **titles/metadata**.

## Never use Unicode sub/superscripts in ReportLab

Use `<sub>`/`<super>` XML tags: `Paragraph("p = 1.2×10<super>-8</super>", style)`. Unicode
₀₁₂/⁰¹² render as black boxes.

## GenerateImage infographic — prompt template

Build the **one-page conceptual infographic** with the `GenerateImage` tool (NOT matplotlib).
Template:

```
A clean one-page scientific infographic titled "Direction of Effect: Activate or Inhibit?".
Show <N> gene targets as labeled cards in a row: <TARGET1> (<INDICATION1>), <TARGET2> ...
Under each target, a large verdict badge reading "INHIBIT" (blue) or "ACTIVATE" (orange),
with its confidence tier ("High", "High-Moderate", ...) beneath in small text.
Down the left side, four small labeled icons for the evidence axes: "Human genetics",
"Functional / CRISPR", "Drug mechanism", "Mouse knockout".
Minimal flat vector style, generous white space, colorblind-safe palette
(blue #0279EE, orange #FF9400, green #75A025, gold #D4A04A), sans-serif labels.
No paragraphs of text, no chart axes — this is a conceptual summary, not a data plot.
```
After generating, run `Read mode="media_output_check"` and regenerate if labels are garbled or
verdicts are wrong. Embed the resulting PNG as the report's figure 1.

## Data-driven figures (make_figures.R / .py)

- **Evidence-matrix heatmap:** rows = targets, columns = axes, fill = vote color; annotate the
  cell with the vote. Green for allele-specific INHIBIT.
- **Consensus summary bar:** horizontal bars, one per target; bar length = # concordant
  informative axes (0–max), fill = confidence tier; label the consensus direction.
- Palette `c("INHIBIT"="#0279EE","ACTIVATE"="#FF9400","INHIBIT (allele-specific)"="#75A025",
  "not_informative"="#ECE9E2")`; `theme_minimal(base_family="Liberation Sans")`; save PNG+SVG,
  `bg="white"`; write to `/mnt/results/...` directly (R `file.copy` gives 0-byte files).
