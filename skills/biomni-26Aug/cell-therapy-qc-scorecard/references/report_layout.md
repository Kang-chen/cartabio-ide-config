# Report Layout — Phylo PDF & infographic summary

`scripts/generate_report.py` builds the PDF following the Biomni
`pdf-report-generation` skill conventions. This page documents the layout,
brand tokens, and the required validation loop.

## Page order

1. **Title block** — report title, gold subtitle "Single-cell RNA-seq lot-release
   characterization", muted "Generated by Biomni | <date>", gold divider.
2. **Infographic summary (page 1)** — one card per unit (see below), then a page
   break. This is the at-a-glance deliverable a reviewer sees first.
3. **Introduction** — what was characterized, the five modules, worst-active-module
   rule, source/target/engineering.
4. **Methods** — loading, species split, QC (MAD + Scrublet + log-norm via
   scanpy-core), and the expression-anchored scoring rationale.
5. **Results** — per-unit metrics table, then Figures 1–4 with captions.
6. **Scorecard & Thresholds** — per-unit×module calls table + thresholds table.
7. **Discussion** — clean vs aberrant target vs true contaminant interpretation.
8. **Limitations** — thresholds-are-defaults; residual-pluripotency LOD caveat.
9. **Next Steps** — orthogonal confirmation, characterize off-target, lock thresholds.
10. **References** — agent-supplied, grounded `[N]` entries (verbatim; never fabricated).

## Infographic summary cards

Two cards per row. Each card:
- **Banner:** unit name + a full-width overall-call block colored GREEN/AMBER/RED.
- **Status strip:** one colored cell per active module (Identity / Pluri / Off-tgt /
  Maturity / Tech QC) with the call text.
- **Metric line:** compact headline (purity %, off-target %, n cells).

This gives a manufacturing reviewer the release decision and the per-module reason
without reading the body.

## Hard-won ReportLab rules (do not regress)

1. **Font color tags need a `#` prefix.** ReportLab's `HexColor.hexval()` returns
   `0xRRGGBB`; `hexval()[2:]` gives `RRGGBB` **without** `#`, and
   `<font color="RRGGBB">` raises. Always write `f'<font color="#{col.hexval()[2:]}">'`.
   (The current template colors calls via table cell backgrounds, avoiding inline
   font tags, but follow this rule if you add any.)
2. **No Unicode super/subscripts** — use `<super>`/`<sub>` tags; Unicode renders as
   black boxes (e.g. write `10<super>4</super>`, not `10⁴`).
3. **Always set `hAlign="CENTER"`** on every `Image`, `Table`, and `Drawing`.
4. **Explicit `colWidths`** on every table; the sum must be ≤ usable width (~492pt).
   The template sizes columns as `usable_width / n_columns`.
5. **Bind figure + caption** with `KeepTogether([...])` so captions don't orphan.
6. **`repeatRows=1`** on multi-row tables so the header repeats across page breaks.
7. **Scale images to the page**: the template reads the PNG's pixel size and scales
   to the usable width preserving aspect ratio (avoids clipping / distortion).

## Validation loop (required)

After building, `validate_pdf(path)` asserts: ≥2 pages, size > 5 KB, and extractable
text on page 1. Then the AGENT must run a visual pass:

```
Read(path=<pdf>, mode="media_output_check")
```

If it reports blank pages, clipped content, or rendering issues, fix and rebuild
before delivering. Do the same `media_output_check` on every figure PNG in
`make_figures.py` — the recurring failure mode is a blank overlay panel from an
integer-obs boolean mask (see methodology caveat #5).
